## 架构决策

用户于 2026-09-15 确认按审查建议实施。保留 MCP、VSIX 和现有工具入口，通过服务提取逐步改进，不整体替换为 CLI。

### 快照身份

- VS 内不可变 Roslyn `Solution` 是当前语义查询的权威快照。
- 给每个快照分配进程内不透明身份；不同解决方案对象、其他 VS 实例和桥接重启不得复用旧身份。
- 快照身份不等于 Git 提交、磁盘文件时间或项目文件版本；未保存缓冲区变化同样导致旧预览失效。
- 通过现有工作区状态返回快照身份。旧 VSIX 不提供身份时，服务端不复用可能陈旧的查询缓存。
- 需要修改磁盘文件时，仍须单独核对磁盘与 VS 缓冲区，不能直接把两者视为一致。

### 修改安全

- Code Fix / Fix All 绑定快照、候选、完整修改摘要；摘要不能从已截断的展示文本推导。
- 应用前在 VS 主线程上再次核对当前快照，防止预览重放期间其他任务修改代码。
- 不支持新安全契约的混合版本必须明确失败，不能静默降级。
- 重命名、清理统一采用相同契约列入后续安全收敛；不宣称所有历史修改入口已自动具备新保护。

### 诊断可信度

- 相关性、级联推断、背景噪声与“是否新增”分别处理。
- 未提供可比基线时输出未知，不因文件是否修改而判断新增/既有。
- 真正基线比较单独验收，不能把“改成未知”标为完成全部诊断基线能力。

### 兼容与交付

- 新字段采用增量协议演进；不改既有枚举数值、不改工具名。
- 保留原调用接口，安全要求提升产生的失败需给出明确重试/升级说明。
- 每批实现后立即补测，不把所有验证压到最后。
- 本地安装状态保持不变；最终安装/发布另行确认。
